简介

AI 开发者空间是面向开发者的智能开发工作空间，以 AI SHELL 为核心入口，通过自然语言交互和命令行两种模式，打通云资源操作、智能代码生成、多 Agent 协作、基础设施即代码（IaC）部署、消息渠道对接、隧道托管与远程连接等全链路开发能力，帮助开发者在统一工作台中高效完成云原生应用的开发、部署与运维。

进入工作台后，左侧为全局导航（AGENTS、TOOLS、环境管理、EXTENSIONS、RESOURCES、文件管理、设置与反馈）与左下角的「会话」区，右侧为资源管理器面板，主区域展示当前功能页。

为什么需要 AI 开发者空间

在华为云上进行开发与运维时，开发者常遇到以下挑战：

  • 云资源操作门槛高：ECS、CCE、OBS 等服务 API 与 CLI 命令繁多，学习成本高
  • 自然语言到命令的转换难：想把想法落地为可执行的云操作命令，需要大量检索与试错
  • 代码理解与重构成本高：大型项目中代码逻辑复杂，缺乏智能化的代码分析与重构建议支持
  • 多云 IaC 编排学习曲线陡峭：多云资源编排需要掌握不同云平台的 IaC 语法，切换成本高
  • 隧道与远程连接配置复杂：本地开发环境与云环境的安全连接配置繁琐，端口管理与转发耗时
  • 能力分散：代码智能体、多 Agent 协作、IaC 部署、隧道管理等工具散落各处，难以协同
  • 多平台集成繁琐：难以将 AI 能力接入飞书、微信、企业微信等消息平台

AI SHELL

AI SHELL 是产品的核心入口，秉持“智驱华为云，对话即部署”的产品理念，大模型驱动，支持自然语言对话、智能排错与云端在线终端，提供三种交互模式：

模式用途说明
AI 对话自然语言交互用自然语言描述需求，AI 生成命令并执行（默认模式）
TUI终端交互终端界面（Terminal UI），面向习惯终端操作的开发者
命令行命令式操作面向熟悉 CLI 的开发者，直接输入命令

操作步骤：

  1. 在左侧 AGENTS 分组下点击 AI Shell，进入 AI 对话界面
  2. 点击 「新建」创建会话，可指定工作目录（CWD），缺省为 /root/workspace
  3. 在输入框用自然语言描述需求（例如"查询所有运行中的 ECS 实例"），按 Enter 发送（Shift+Enter 换行）
  4. 输入 /mode 可随时切换「AI 对话」「TUI」「命令行」模式
AI SHELL 主界面：居中欢迎页、快捷建议与需求输入框

输入增强：

  • 输入 / 触发快捷指令：/clear、/compact、/cwd、/help、/mode、/model、/new、/rename、/sessions、/settings
  • 输入 $ 快速引用技能
  • 右侧资源管理器中可将文件「添加到对话」作为上下文

点击输入框左下方的 mode: Semi-Auto 按钮，可打开会话配置：

配置项说明可选值
Session Mode控制 AI 的自主性与安全边界Auto / Semi-Auto（默认）/ Manual / Plan

AGENTS 概览

AGENTS 分组位于左侧导航顶部，根据已部署的环境状态动态展示智能体入口，未部署或待开放的环境不会出现在导航中。 当前共 14 个智能体，其中 SRE 待开放，覆盖代码生成、多 Agent 协作、个人助手、模型推理、AI 教学等场景：

进入与使用：

  1. 展开左侧 AGENTS 分组，点击智能体名称进入其默认入口（TUI 或 WebUI）
  2. 表中标注 TUI / WebUI 的智能体，点击名称进入终端界面；在名称右侧点击 WebUI 按钮进入网页界面
  3. 在终端或网页界面中按页面提示输入任务；切换到其他菜单即离开当前智能体，可随时从左侧再次进入
看不到某个智能体？左侧导航只展示已部署的环境。请到 环境管理 部署并启动对应环境，状态变为「运行中」后即可在 AGENTS 中出现。
TUI 空白或跳回首页？通常是环境仍在启动或终端端口未就绪。等待 1–2 分钟后重新点击；仍无法进入时，在环境管理中停止后重新启动环境再试。

鸿蒙实践中心

鸿蒙实践中心 基于 GLM 模型鸿蒙增训、深度适配 ArkTS 语言，提供云端编译打包与云端 + 本地模拟器调测能力，通过 WebUI 使用（在环境管理中归类为开发工具）。工作台左侧分为项目管理（CodeArts Web、CodeArts CLI、Skills 管理）与设备管理（鸿蒙云模拟器、本地真机&模拟器），并内置最佳实践。

操作步骤：

  1. 点击左侧 AGENTS 分组下的 鸿蒙实践中心，打开 WebUI 工作台
  2. 点击 新建项目 创建鸿蒙工程，或通过 连接 GitCode 导入已有仓库
  3. 在项目中使用 CodeArts Web / CLI 编写代码，调用云端编译打包能力构建 HAP
  4. 在设备管理中选择鸿蒙云模拟器或本地真机完成安装与调测

链接生成（BETA）

链接生成 用于把 AI 开发者空间中的指定位置（AI Shell 会话、某个作业环境、自定义启动流程）转换为一条可分享的推广链接（URL to ENV）。接收方打开链接即可直达对应入口，无需再逐级查找；链接支持渠道追踪与二维码下载，适合在文档、工单与教学场景中分发环境。

页面提供两种生成方式，可随时切换：

  • 表单生成：选择场景后按表单填写参数；表单区提供「表单 / JSON」切换，需要精确配置或批量复用时可改用 JSON 编辑。
  • AI 生成：用一句话描述要生成的链接，交给 AI Shell 完成配置。
进入「链接生成」后先切换「表单生成 / AI 生成」，再在「选择场景」中选一种场景
说明：页面顶部显示「历史链接」数量（如「历史链接 1」），用于查看已生成的链接。三种场景共用 基础地址 与 渠道（运维） 两个通用字段：前者通常已按场景预填，一般无需修改；后者用于标记推广来源（如 CSDN、GitCode、华为云官网等），可留空。

适合没有现成环境、需要「先执行几条命令再启动服务」的场景：把准备命令与启动命令一起写进链接，接收方打开后按顺序执行，并直接进入服务页面。

系统指标卡

顶部 5 张指标卡展示宿主机整体资源状态：

指标卡说明
CPU 使用率当前 CPU 使用率百分比，展示核数与 1/5/15 分钟平均负载（load 1.4/1.2/0.9 形式），上限 100%
内存已用 / 总内存（如 5.3 GB / 14.9 GB）、使用率百分比与可用内存；点击「内存明细说明」查看内存统计口径

磁盘 /根分区已用 / 总容量、使用率百分比与可用空间

作业环境资源

按环境维度展示资源占用。统计行汇总「已部署 / 运行中环境数」与「内存合计」，支持按 全部 / 智能体 / 开发工具 / 数据库 分类筛选。每个环境一张卡片，字段如下：

  • 内存 RSS：该环境进程常驻内存
  • CPU：当前 CPU 使用率
  • 目录：环境目录的磁盘占用
  • 运行进程：进程数与主进程类型（agent / client）
  • 状态与类型：运行状态（如运行中）与所属分类（智能体 / 开发工具 / 数据库）

资源占用排行

列出资源占用最高的 TOP 12 环境（不含系统进程），支持按内存 / CPU / 磁盘三种指标降序排序，便于快速定位高消耗环境。

统计口径：内存为宿主机 /root/runtime/<环境> 目录下进程 RSS 聚合；沙箱内 free 命令结果为宿主共享视图，不代表单环境实际占用；CPU 为 /proc 两次采样差（单核口径）。
