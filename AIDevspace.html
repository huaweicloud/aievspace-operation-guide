简介

AI 开发者空间是面向开发者的智能开发工作空间，以 AI SHELL 为核心入口，通过自然语言交互和命令行两种模式，打通云资源操作、智能代码生成、多 Agent 协作、基础设施即代码（IaC）部署、消息渠道对接、隧道托管与远程连接等全链路开发能力，帮助开发者在统一工作台中高效完成云原生应用的开发、部署与运维。

核心能力

模块说明
AI SHELL核心入口，支持 AI 对话（自然语言交互）和命令行两种模式
AGENTS8 个智能体，覆盖代码生成、多 Agent 协作、基础设施即代码、个人助手、DeepSeek 推理、SRE 运维等场景
环境管理14 个作业环境，支持智能体、开发工具、数据库、基础设施四类分类，一键部署与管理

为什么需要 AI 开发者空间

在华为云上进行开发与运维时，开发者常遇到以下挑战：

  • 云资源操作门槛高：ECS、CCE、OBS 等服务 API 与 CLI 命令繁多，学习成本高
  • 自然语言到命令的转换难：想把想法落地为可执行的云操作命令，需要大量检索与试错
  • 代码理解与重构成本高：大型项目中代码逻辑复杂，缺乏智能化的代码分析与重构建议支持
  • 多云 IaC 编排学习曲线陡峭：多云资源编排需要掌握不同云平台的 IaC 语法，切换成本高
  • 隧道与远程连接配置复杂：本地开发环境与云环境的安全连接配置繁琐，端口管理与转发耗时
  • 能力分散：代码智能体、多 Agent 协作、IaC 部署、隧道管理等工具散落各处，难以协同
  • 多平台集成繁琐：难以将 AI 能力接入飞书、微信、企业微信等消息平台

AI SHELL

AI SHELL 是产品的核心入口，提供两种交互模式：

模式用途说明
AI 对话自然语言交互用自然语言描述需求，AI 生成命令并执行
命令行命令式操作面向熟悉 CLI 的开发者，直接输入命令

操作步骤：

  1. 点击左侧 AI SHELL，进入对话界面
  2. 在顶部切换「AI 对话」或「命令行」模式
  3. 点击输入框，用自然语言描述需求（例如"查询所有运行中的 ECS 实例"）并发送
  4. 点击「创建会话」或「新建」可开启新的对话
AI SHELL 主界面：AI 对话模式、快捷建议与输入框

点击输入框左侧的 mode: Manual 按钮，可配置会话参数：

配置项说明示例
Session Mode控制 AI 的自主性与安全边界Manual（手动确认执行）
Reasoning Level控制模型产生的推理量Medium（中等）
Model选择使用的 LLM 模型hwdevspace/glm-5.2
会话配置面板：Session Mode / Reasoning Level / Model

AGENTS 概览

AGENTS 模块默认展示 HWCloud CLI、CodeArts、JiuwenSwarm、DeepSeek Harness 智能体，根据部署的环境状态动态展示 Agent 入口， 目前可以提供 8 个智能体，覆盖代码生成、多 Agent 协作、基础设施即代码、个人助手、DeepSeek 模型推理等场景。

HWCloud CLI

HWCloud CLI 是基础设施即代码（IaC）智能体，支持 Terraform、Ansible 等工具，可将自然语言需求转换为可执行的基础设施配置。

操作步骤：

  1. 点击左侧菜单 HWCloud CLI，进入该智能体
  2. 用自然语言描述基础设施需求（例如"创建一个 VPC 和一个 ECS 实例"）
  3. HWCloud CLI 调用 Terraform / Ansible 等工具生成 IaC 脚本
  4. 确认脚本后执行部署，并查看运行结果
HWCloud CLI：基础设施即代码智能体

CodeArts

CodeArts 是华为云码道代码智能体 CLI，支持代码编写、分析与优化。支持 TUI（终端模式） 和 WebUI（网页模式） 两种使用方式。

操作步骤：

  1. 点击左侧菜单 CodeArts，进入该智能体
  2. 选择使用模式：TUI（点击名称直接进入终端界面）或 WebUI（点击右侧 WebUI 按钮进入网页界面）
  3. 在 TUI 终端或 WebUI 网页中输入代码编写、分析或优化需求
  4. CodeArts 生成代码建议或分析报告，确认后执行查看结果

TUI 模式（终端界面）

CodeArts TUI：终端模式，直接在命令行中交互

WebUI 模式（网页界面）

CodeArts WebUI：网页模式，可视化操作界面

JiuwenSwarm

JiuwenSwarm 是多 Agent 协作框架，可自动将复杂任务分解并分配给不同 Agent 协作完成。支持 TUI（终端模式） 和 WebUI（网页模式） 两种使用方式。

操作步骤：

  1. 点击左侧菜单 JiuwenSwarm，进入该智能体
  2. 选择使用模式：TUI（点击名称直接进入终端界面）或 WebUI（点击右侧 WebUI 按钮进入网页界面）
  3. 输入一个复杂任务
  4. JiuwenSwarm 自动分解任务并分配给不同 Agent 协作处理
  5. 查看各 Agent 的协作结果

TUI 模式（终端界面）

JiuwenSwarm TUI：终端模式

WebUI 模式（网页界面）

JiuwenSwarm WebUI：网页模式，多 Agent 可视化协作

DeepSeek Harness

DeepSeek Harness 是基于 DeepSeek 大模型的 AI 推理智能体，支持高效模型推理、代码生成与自然语言理解，可无缝集成到开发工作流中。支持 TUI（终端模式） 和 WebUI（网页模式） 两种使用方式。

操作步骤：

  1. 点击左侧菜单 DeepSeek Harness，进入该智能体
  2. 选择使用模式：TUI（点击名称直接进入终端界面）或 WebUI（点击右侧 WebUI 按钮进入网页界面）
  3. 输入推理、代码生成或分析需求
  4. DeepSeek Harness 调用模型进行推理并返回结果
  5. 查看推理结果，根据需要调整提示词并重新执行

TUI 模式（终端界面）

DeepSeek Harness TUI：终端模式

WebUI 模式（网页界面）

DeepSeek Harness WebUI：网页模式，支持会话编排与技能管理

OpenViking

OpenViking 是智能开发辅助工具，帮助开发者理解代码、提供重构建议与自动化开发支持。支持 TUI（终端模式） 和 WebUI（网页模式） 两种使用方式。

操作步骤：

  1. 点击左侧菜单 TOOLS → OpenViking，进入该工具
  2. 选择使用模式：TUI（点击名称直接进入终端界面）或 WebUI（点击右侧 WebUI 按钮进入网页界面）
  3. 选择目标代码文件或项目目录
  4. OpenViking 分析代码并生成理解报告或重构建议
  5. 确认建议后执行相应操作

TUI 模式（终端界面）

OpenViking TUI：终端模式

WebUI 模式（网页界面）

OpenViking WebUI：网页模式，代码智能助手

IACMCPServer

IACMCPServer 是基础设施即代码 MCP 服务，通过 MCP（Model Context Protocol）协议对外暴露 IaC 能力，支持多云资源编排与管理。目前仅支持 TUI（终端模式）。

操作步骤：

  1. 点击左侧菜单 TOOLS → IACMCPServer，进入该工具
  2. 配置目标云平台的认证凭证
  3. 通过 MCP 协议发送基础设施编排指令
  4. 查看编排结果与资源状态

TUI 模式（终端界面）

IACMCPServer TUI：基础设施即代码 MCP 服务（终端模式）

DevBridge

DevBridge 是隧道管理工具，提供开发者隧道能力，支持托管（Host）将本地端口服务暴露到公网隧道，以及连接（Connect）将远端隧道端口转发到本地。支持 TUI（终端模式） 和 WebUI（网页模式） 两种使用方式。当在环境管理中部署 DevBridge 环境后，会在 TOOLS 菜单下展示入口。

操作步骤：

  1. 在 环境管理 中部署 DevBridge 环境
  2. 部署完成后，左侧 TOOLS 菜单下会出现 DevBridge 入口
  3. 选择使用模式：TUI（点击名称直接进入终端界面）或 WebUI（点击右侧 WebUI 按钮进入管理控制台）
  4. TUI 模式下可通过命令行管理隧道；WebUI 模式下可在控制台创建隧道、管理端口映射与托管/连接进程

TUI 模式（终端界面）

DevBridge TUI：终端模式，通过命令行管理隧道

WebUI 模式（网页界面）

DevBridge WebUI：隧道管理控制台，可视化创建和管理隧道
