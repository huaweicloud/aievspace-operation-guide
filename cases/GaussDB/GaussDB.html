1案例介绍

本案例的核心理念是：“环境即链接，开箱即练”。传统上学习一款分布式数据库，往往要先申请资源、装驱动、配网络、等初始化，门槛高、耗时长。AI 开发者空间把这套流程下沉为平台能力——它为你预置好云端工作环境（WorkEnv），并通过一条可分享的链接直接把你“送进”环境里。

什么是 AI 开发者空间

华为云官方云端开发环境，内置 AI Shell 与 hcloud CLI，浏览器内即可完成开发、调试与运行，无需本地安装。

什么是环境管理

平台以“工作环境”为单位管理开发资源。GaussDB 环境已预装数据库客户端与连接配置，进入即用。

什么是 GaussDB

华为云自研的企业级分布式数据库，兼容 MySQL / PostgreSQL，具备高可用、弹性伸缩与金融级可靠。

为什么要做这个案例

  • 零搭建成本：免去资源申请、驱动安装、网络配置等前置步骤，打开链接即可上手。
  • 视频 + 实操闭环：先看官方视频建立认知，再在真实环境里动手，知识记得牢。
  • 可分享、可复现：URL TO ENV 链接可发给同学/同事，每个人进入的都是同一套标准环境，结果一致。
  • 贴合平台范式：本案例沿用 AI DevSpace 实践页的“介绍 → 收获 → 前置 → 实操 → 排障 → 清理”结构，迁移到其他 WorkEnv 同样适用。

2

连接 GaussDB 并确认版本

在环境终端中使用预置的连接命令/客户端连上数据库，先确认版本与兼容模式（GaussDB 兼容 MySQL 或 PostgreSQL，语法略有差异，请按环境实际提示选择）。

# 示例（GaussDB 兼容 MySQL 模式，具体命令以环境内提示为准） gsql / mysql -h <环境提供的host> -u <user> -p SELECT version();

完成标志：✅ 成功进入数据库命令行，version() 有返回。

3

建库、建表、写入示例数据

按视频里“典型场景”的思路，创建一个业务库与一张订单表，插入几条样例数据。下面给出兼容 MySQL 模式的示例：

-- 创建业务数据库
CREATE DATABASE shop DEFAULT CHARACTER SET utf8mb4;
USE shop;

-- 创建订单表（体现 GaussDB 的分布式/高可用能力：普通 DDL 即可）
CREATE TABLE orders (
  id        BIGINT PRIMARY KEY AUTO_INCREMENT,
  customer  VARCHAR(64)  NOT NULL,
  amount    DECIMAL(10,2) NOT NULL,
  status    VARCHAR(16)  DEFAULT 'NEW',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 插入示例数据
INSERT INTO orders(customer, amount, status) VALUES
  ('Alice', 199.00, 'PAID'),
  ('Bob',   59.90, 'NEW'),
  ('Carol', 899.00, 'PAID');

完成标志：✅ 表创建成功，SELECT COUNT(*) FROM orders; 返回 3。

4

查询与聚合：体验 GaussDB 的分析能力

借助 HTAP 能力，事务表上直接跑分析查询（这正是视频里强调的“一套引擎兼顾 TP 与 AP”）：

-- 已支付订单总额与笔数
SELECT status,
       COUNT(*)        AS cnt,
       SUM(amount)    AS total
FROM orders
GROUP BY status;

-- 单笔最大订单（体验分布式下的聚合）
SELECT customer, amount
FROM orders
ORDER BY amount DESC
LIMIT 1;

8安全与清理

  • 链接管理：环境直达链接相当于进入该环境的钥匙，仅分享给可信对象；疑似泄露时回到平台回收/重生成令牌。
  • 凭据不外泄：数据库连接信息只在环境内使用，不要写入聊天、代码、截图或公开仓库。
  • 及时清理：实践完成后，按 AI DevSpace 平台规则停止或释放 GaussDB 环境，删除练习用的测试库表，避免不必要的资源占用。
  • 数据合规：本案例使用自建的样例数据，请勿在其中存放真实业务或个人敏感数据。
